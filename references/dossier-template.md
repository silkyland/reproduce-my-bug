# Repro Dossier Template

Write to `REPRO.md` (single active bug) or `docs/repro/<slug>.md`. The
dossier is the deliverable a fixer can pick up cold.

---

```markdown
# Repro: <one-line bug title>

> Generated by reproduce-my-bug on <date>. Status: **DETERMINISTIC /
> RATE-BASED (n/N) / NOT-YET-REPRODUCED**.

## Symptom

- Reported: "<verbatim quote from the report>"
- Expected: <...>  Actual: <...>
- Environment: <commit/version, runtime, locale/TZ>  First seen: <date/version>
- Frequency reported: <always / sometimes / once>

## The reproduction  ← run this

- **Artifact:** `tests/.../test_<slug>.py` (failing test) / `repro/<slug>.sh`
- **Command:** `<exact command>`
- **Failing output (verbatim):**

    <paste the actual red output>

- **Triggering conditions** (all load-bearing — removing any makes it pass):
  1. <e.g. row with discount = NULL (pre-2026_05 migration rows)>
  2. <e.g. locale th_TH — date parse path>
- (Flaky) **Forcing recipe:** <frozen clock / seed / hammer script> — rate <n/N> without forcing.

## Evidence timeline

| When | Evidence | Source |
|------|----------|--------|
| <ts> | NPE at `src/Cart/Calc.php:88` | `storage/logs/app-2026-07-04.log:1123` |
| <date> | migration backfilled only active rows | commit `ab12cd3` |

## Hypotheses

- ❌ **<killed hypothesis>** — eliminated by <attempt/observation> (attempt log #3)
- ❌ …
- ✅ **Suspected root cause:** <statement> — `VERIFIED (file:line)` or
  `UNVERIFIED — repro confirms the behavior; cause needs <what>`

## Attempt log

| # | Changed (one variable) | Result |
|---|------------------------|--------|
| 1 | replayed request with prod payload | no repro |
| 2 | + discount=NULL row | **reproduced** |

## Handoff

- This failing test is the fix's acceptance criterion — the fix is done
  when it turns green WITHOUT editing the test's assertions.
- Keep the test after the fix: it is the permanent regression guard.
- <If the fix needs design: run deep-plan with this dossier as input.>
- <Monitoring to add if NOT-YET-REPRODUCED.>
```

---

## Quality bar

- A fixer who has never seen this conversation can run the repro in
  under a minute and watch it fail.
- Every timeline row has a source; every killed hypothesis names its
  killer; nothing in the dossier is remembered — it's all quoted.
- The status line never oversells: rate-based is labeled rate-based,
  not-yet is labeled not-yet.
